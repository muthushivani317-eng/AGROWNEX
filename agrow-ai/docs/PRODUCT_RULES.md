# PRODUCT RULES

1. Tamil is the default language.

2. Farmers never pay to use AgrowAI.

3. Never recommend a pesticide or fertilizer brand unless explicitly configured by the business.

4. Government schemes must come only from verified official sources.

5. Weather data must come from Open-Meteo.

6. AI should clearly state uncertainty instead of guessing.

7. Every feature must save time, reduce costs, or increase farmer income.

8. Every screen must support offline caching where practical.

9. Every API must include authentication, logging, and error handling.

10. Follow Feature-Based Clean Architecture.

11. Reusable components only.

12. No duplicate code.

13. Maintain TypeScript strict mode.

14. Every new feature must include tests.

15. Performance and accessibility are first-class requirements.
