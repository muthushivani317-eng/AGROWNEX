# Production design system

- Theme: deterministic premium light theme.
- Background: warm neutral `#F6F7F2` / token `#F7F9F4`.
- Brand: agricultural green `#2E7D32`.
- Cards: white, subtle `#E1E7DE` border, 20dp radius, restrained elevation.
- Text: `#111827`; muted `#6B7280`; no mixed dark surfaces.
- Inputs: explicit white background, dark text, visible labels/cursor/borders.
- Touch targets: 48dp for header buttons and chips; 56dp normal buttons.
- Layout-critical flex, dimensions, backgrounds, borders and padding now have native fallbacks in repaired surfaces.
- Dark mode: intentionally deferred until every feature has complete parity.
