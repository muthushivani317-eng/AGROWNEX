# Component inventory

- `AuthBrandHeader`: bounded high-resolution icon and native wordmark.
- `AuthErrorBanner`: accessible inline error/retry presentation.
- `AgInput`: labelled native field, focus/error border, readable text and accessories.
- `AgButton`: native visual container with filled, outline, loading, disabled, and press states.
- `AgOtpInput`: six visible cells backed by one autofill/paste-capable numeric input.
- `AgLanguageToggle`: large Tamil/English segmented control used on login.
- `LanguageSelectScreen`: two large radio-card options and a prominent Continue action.
- `LoginScreen`: branded hero, phone card, primary/Google actions, errors, and legal copy.
- `VerifyOtpScreen`: back action, security hierarchy, OTP card, verify action, resend timer, and change-number action.
