# Crop-identification reason codes

- `INVALID_IMAGE_FORMAT`, `CORRUPT_IMAGE`, `IMAGE_DECODE_FAILED`
- `IMAGE_TOO_LARGE`, `IMAGE_TOO_SMALL`, `IMAGE_TOO_BLURRY`
- `IMAGE_TOO_DARK`, `IMAGE_OVEREXPOSED`
- `CROP_IDENTIFICATION_UNCERTAIN`, `INVALID_GEMINI_RESPONSE`
- `GEMINI_CONFIGURATION_MISSING`, `GEMINI_RATE_LIMITED`, `GEMINI_TIMEOUT`, `GEMINI_REQUEST_FAILED`
- `CROP_ID_REQUEST_NOT_FOUND`, `CROP_CONFIRMATION_REQUIRED`, `CROP_CONFIRMATION_EXPIRED`
- `CROP_ID_REQUEST_OWNERSHIP_MISMATCH`, `CROP_SELECTION_MISMATCH`, `CROP_IMAGE_MISMATCH`
- `CROP_CONFIRMATION_REPLAYED`
- `TESTER_ROLE_REQUIRED`, `DISEASE_MODEL_NOT_AVAILABLE`, `DISEASE_MODEL_DISABLED`

Clients must map unknown codes to a safe retry/unavailable message and never infer success.
