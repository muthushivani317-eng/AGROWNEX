# Farmer Pilot Consent

This is a voluntary controlled pilot. Results may be incorrect and may abstain.
No payment is required. Data is collected only for testing. Recommendations are
not automatically provided. KVK verification is required before treatment.

Record pilot session ID, consent, UTC date/time, district, optional village,
language, consent version, tester ID, and optional KVK reviewer code. Tamil text:
`HUMAN_TAMIL_REVIEW_REQUIRED`.
