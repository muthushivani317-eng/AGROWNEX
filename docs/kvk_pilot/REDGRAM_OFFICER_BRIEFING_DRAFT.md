# Redgram diagnosis — KVK officer briefing (draft for review)

> **Review status:** Draft only. This safety wording requires explicit approval
> before it is used in training or shown to farmers.

## English

Redgram diagnosis is a newer feature that is still being checked in real field
conditions. When the system suspects leaf spot, it deliberately does not give a
diagnosis rather than risk guessing. Please treat that response as a safety choice
and inspect the crop directly.

Testing so far used a small set of images from one source. Real-world performance is
therefore still being established. KVK supervision and feedback are especially
important for Redgram during this stage.

## தமிழ்

துவரை நோய் கண்டறிதல் என்பது தற்போது உண்மையான வயல் சூழலில் சோதிக்கப்பட்டு வரும்
புதிய அம்சமாகும். இலைப்புள்ளி நோய் இருக்கலாம் என்று அமைப்பு சந்தேகித்தால், தவறாக
ஊகிப்பதைத் தவிர்க்க அது நோய் முடிவை வழங்காது. இதை ஒரு பாதுகாப்பு நடைமுறையாகக்
கருதி, பயிரை நேரடியாகப் பரிசோதிக்கவும்.

இதுவரையிலான சோதனை ஒரே மூலத்திலிருந்து பெறப்பட்ட குறைந்த எண்ணிக்கையிலான
படங்களைக் கொண்டு செய்யப்பட்டது. ஆகவே உண்மையான வயல் செயல்திறன் இன்னும்
உறுதிப்படுத்தப்பட்டு வருகிறது. இந்த நிலையில் துவரைக்கான KVK மேற்பார்வையும்
கருத்துப் பதிவும் மிகவும் முக்கியமானவை.
