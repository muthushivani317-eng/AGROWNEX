# Security and evidence limitations

- The model is a public-dataset provisional runtime.
- Tamil Nadu field performance and farmer-photo robustness are unknown.
- Non-plant and unsupported-plant rejection are not proven.
- No official accuracy claim is allowed.
- General farmer inference is blocked.
- Tester access is revocable and server-authoritative.
- Client role claims are ignored.
- Real Firebase HTTP identity tests require a configured emulator or test
  project; mocked tests are not described as real authentication proof.
